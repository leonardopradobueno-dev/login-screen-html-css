# Simple Login Page 

A simple login screen created using **HTML** and **CSS**. This project demonstrates basic front-end web development skills and can serve as a foundation for more advanced web projects.

## Features

- Clean and modern design
- Login form with username and password fields
- "Remember me" checkbox and "Forgot password" link
- Subscribe link for new users

## Technologies Used
  
- HTML5
- CSS3 
- Boxicons for icons

## How to View
  
- Open the **login.html** file in your browser to see the login screen.
